# Yoyo

**[Yoyo](https://yoyocards.fr)** (yoyocards.fr) : des fiches de révision à partir d'une photo de la leçon, revues avec la méthode de la boîte de Leitner.

*English below.*

## Installer l'application

- **[App Store (iOS)](https://apps.apple.com/app/id6822239489)**
- **Android (APK)** : chaque version de Yoyo est publiée ici, dans les [Releases](https://github.com/hubyrod/yoyocards-app/releases). La dernière est sur [releases/latest](https://github.com/hubyrod/yoyocards-app/releases/latest) : téléchargez `yoyo-X.Y.Z.apk` sur le téléphone, ouvrez-le, et autorisez l'installation depuis cette source quand Android le demande. Pour mettre à jour, installez le nouvel APK par-dessus l'ancien : les fiches et la progression restent.

## Pourquoi ce dépôt

Le code de Yoyo est privé. Ce dépôt sert seulement à :

- **suivre les bugs et les idées** en public, et
- **héberger l'APK Android** de chaque version.

Il n'y a pas de code ici, et il n'y en aura jamais.

## Signaler un bug

Ouvrez un [nouveau ticket](https://github.com/hubyrod/yoyocards-app/issues/new/choose) en indiquant :

- la **version de l'application** (en bas de « Mon profil », par exemple `Yoyo v1.4.2 (12)`),
- la **plateforme** (Android, iOS ou le site),
- **les étapes** pour reproduire ce que vous avez vu.

Les tickets sont publics : n'y mettez pas de nom d'élève, de photo de leçon avec un nom dessus, de mot de passe ni d'autre donnée personnelle.

## Ce qui n'a pas sa place ici

- **Les pull requests** : le code n'est pas dans ce dépôt, il n'y a rien à fusionner.
- **Les failles de sécurité** : jamais en ticket public, voir ci-dessous.

## Sécurité

Si vous pensez avoir trouvé une faille de sécurité, n'ouvrez **pas** de ticket public. Écrivez en privé à **[hubyrod@pm.me](mailto:hubyrod@pm.me)**.

## Délais de réponse

Les tickets sont traités dans la mesure du possible, sans engagement de délai.

# Yoyo (English)

**[Yoyo](https://yoyocards.fr)** (yoyocards.fr): revision cards drafted from a photo of the lesson, reviewed with the Leitner box method.

## Get the app

- **[App Store (iOS)](https://apps.apple.com/app/id6822239489)**
- **Android APK**: every Yoyo release publishes an installable APK on this repo's [Releases page](https://github.com/hubyrod/yoyocards-app/releases); grab the latest from [releases/latest](https://github.com/hubyrod/yoyocards-app/releases/latest). Download `yoyo-X.Y.Z.apk` on the phone, open it, and allow installs from this source when Android asks. To update, install the newer APK over the old one: cards and progress stay.

## Why this repo exists

Yoyo's source code is private. This repository exists only to:

- **track bugs and feature requests in the open**, and
- **host public APK downloads** of each release.

There is no source code here, and there never will be.

## How to file an issue

Open a [new issue](https://github.com/hubyrod/yoyocards-app/issues/new/choose) and please include:

- the **app version** (at the bottom of "Mon profil", e.g. `Yoyo v1.4.2 (12)`),
- your **platform** (Android / iOS / web),
- **steps to reproduce** what you saw.

Issues are public: please do not include a pupil's name, a photo of a lesson with a name on it, passwords, or any other personal data.

## What belongs here / what doesn't

**Belongs here:** bug reports, feature requests, questions about the app's behaviour.

**Doesn't belong here:**

- **Pull requests**: the code isn't in this repo, so there is nothing to merge.
- **Security vulnerabilities**: never file these as public issues; see below.

## Security

If you believe you've found a security vulnerability, do **not** open a public issue. Report it privately to **[hubyrod@pm.me](mailto:hubyrod@pm.me)**.

## Response expectations

Issues are triaged on a best-effort basis. There is no SLA.
